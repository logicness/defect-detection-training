# 缺陷检测模型训练代码库

工业表面缺陷检测项目的模型训练部分（基于 Ultralytics YOLOv8/v11）。
包含训练脚本、评估脚本、数据集组织说明与实验记录。

> 说明：本仓库只含**训练代码、配置与文档**。模型权重、数据集与训练产物（runs/logs/models/datasets）
> 体积大且不便于版本管理，未纳入本仓库；请按本地环境自行准备。

## 目录结构
- `scripts/`：训练 / 验证 / 预测脚本
- `*.yaml`：数据集与模型配置
- `*.md`：实验记录与计划文档

## 本地路径说明
文档中出现的 `<LOCAL_MODEL_PATH>` / `<LOCAL_ROOT>` 为你本地的代码与数据集根目录占位符；
`<proxy-host>:<proxy-port>` 为可选的下载代理地址，请按你的环境替换。
